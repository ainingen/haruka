# ハルカのセッティングノート

リポジトリ名：`haruka`
カーチューニング × レースゲーム（ブラウザ / HTML5・PLiCy公開想定）

## 一行で

弱小チームのオーナーとなり、天才少女ドライバー・神谷ハルカと組んで、車をチューニングしながら
草レースからトップカテゴリーまで駆け上がるシミュレーションゲーム。

## 設計の核

1. **絵で戦わない** — 車は図面様式の線画SVG。コースは線、車は点。実写風の車両画像を一切使わない。
2. **チューニングは本物の理屈で** — すべてのパーツにトレードオフがある。攻略ではなく理解でタイムが縮む。
3. **解説がそのまま物語** — パーツの説明は「父のセッティングノートの書き込み」として提示される。
4. **実装は素の HTML5 + SVG + JS** — フレームワーク・ビルドツールは使わない（PLiCy 公開の制約）。

## 題名について

『ハルカのセッティングノート』は二重の意味を持つ。

- 序盤〜中盤：ハルカが父・大河から受け継いだノート
- クラス5：父の記述が尽き、ハルカ自身が書き始めるノート

題名の回収がそのまま物語の到達点になる。
