# クラス5台本『ハルカのセッティングノート』v1

範囲：クラス5昇格 → クラス5本編（差し込み） → 優勝 → エンディング → 白紙のページ
想定プレイ時間：昇格2分、エンディング4分

前提
- プロローグ台本 v3 と キャラクター.md に従う。ハルカ17歳、一人称「ウチ」、主人公を「アンタ」。
- 大河はクラス5に上がった直後、他車の事故に巻き込まれて他界。ノートはクラス4で終わっている。事故そのものは描かない。
- エンディングでハルカは主人公を名前ではなく「おいちゃん」と呼ぶ（第1場「手伝ったやつの名前は、勝ったときだけ言え」への返事）。プロローグ第4場で一度漏れて以来、二度目。
- プレイヤーの入力した名前は、ハルカの口からは出さない。スタッフが呼ぶときだけ使う。
- 第3場でプレイヤーが書いたノートの一行（既定「きょう　あたしがきめた。おいちゃんとふたりで」）をエンディングで回収する。
- ノートを「ハルノート」と呼ばせない。

表記
- 【 】＝画面演出・システム
- ［ ］＝プレイヤー操作
- 台詞は「話者：台詞」
- ｛名前｝＝プレイヤーの入力した名前
- ｛一行｝＝第3場でプレイヤーが書いた一行

## 備考

- 第5場の「一戦だけ、走った」「言うな」——事故の場所を明示せずに、ハルカが知っていることだけを示す。これ以上は言わない。
- 第6場でハルカが「おいちゃん」と言う直前、必ず間を置く。ここで名前（｛名前｝）を呼ばせない。名前はスタッフAが呼ぶ。プロローグ第4場で一度漏れた「おいちゃん」を、今度はハルカが選んで言う。
- 第7場の「セッティングって、正解ないなら、なんでやるの」は第3場のハルカの問いの反復。答える側が大河から主人公に替わっている。答えの前半は大河の言葉をそのまま、後半（「ハルが一番聞いてる」）だけが主人公の言葉。
- 「親父と同じこと言ってる」「うるさい」は第5場・第7場で立場を入れ替えて二度使う。三度は使わない。
- 既定文「今日、ウチが決めた。おいちゃんとふたりで」は第3場の既定文と同じ文（一人称と漢字だけが変わる）。プレイヤーが第3場で別の文を書いていた場合も、第7場の既定文はこれで固定。プレイヤーが第7場でも自分の文を書けば、それが並ぶ。
- 表紙に「ハルカ」を書き足す演出は、タイトル『ハルカのセッティングノート』がここで成立する、という意味。
- 第8場の自由設定の無線は、既存の症状系（熱・剛性・信頼性）の台詞をそのまま流用してよい。増やすのは上の6本だけ。

## 実装メモ（Opus へ）

- 第5場：season.js の `note_ends` イベントで season.html に出す。すでに枠はある。
- 本編差し込み：radio.json に `class5_first_works` / `class5_first_reinforce` / `class5_works_retire` / `class5_braced_finish` の4トリガーと、season_note のクラス5用3本。
- 第6場：シーズン優勝が確定した決勝の終了時。race.html → season.html の間に挿入。背景は常に kazahaya。
- 第7場：第6場の直後、続けて出す。第3場の一行は state の `prologue.line`。第7場の入力は state に `ending.line`（40字）を足す。
- スタッフロールの背景は、ノートのページ画像をめくる演出。ページの中身はテキストで組んでよい（大河の字＝紙の明朝、子どもの字・ハルカの字は書体があれば別、無ければ同じ）。
- 第8場：エンディング後、index.html に「白紙のページ」の項目を足す（つづきからの下）。タイムアタック画面は別途。
- 表紙の「ハルカ」書き足しは、エンディング後の index.html の表紙表示に反映する（「TAIGA」「はるか」「ハルカ」の三段）。
