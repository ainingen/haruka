# クラス構成と解禁範囲

## 基本の考え方

現実のレースにおける「クラス」は、要するに**改造範囲の規定**である。
これをそのままゲームの成長段階として使う。クラスが上がる＝チューニングの解禁範囲が広がる。

名称はすべて架空。実在のシリーズ名・ブランド名は商標のため使用しない。

## 5段階

### クラス1 — 走行会・草レース
- 車両：ハッチバック
- 解禁：純正 + 軽い吸排気、タイヤ、空気圧
- 勝負どころ：タイヤ選択と空気圧、ギア比
- スポンサー：なし（自腹）。パーツは中古・純正流用のみ

### クラス2 — 地方選手権（ワンメイク相当）
- 車両：セダン
- 解禁：社外サス（車高調）、ブレーキ、軽量化
- 勝負どころ：改造制限が厳しいぶん、セッティングの腕がそのまま出る
- スポンサー：地元の整備工場、飲食店など。小額だが継続的

### クラス3 — 全国耐久（ST相当）
- 車両：セダン〜GT
- 解禁：エンジン内部、LSD、エアロキット
- 勝負どころ：燃費、タイヤ摩耗、ピット戦略が加わる
- スポンサー：地方チェーン。ワンオフパーツが手に入る

### クラス4 — GT下位相当
- 車両：GT
- 解禁：過給機、本格空力、大幅軽量化
- 勝負どころ：空力とエンジンのバランス。コース特性が強く出る
- スポンサー：全国区の企業（架空名）。セミワークス級

### クラス5 — トップカテゴリー
- 車両：GT / フォーミュラ
- 解禁：開発パーツ、専用設計
- 勝負どころ：性能調整（BoP）で横並びにされた中での詰め
- スポンサー：大手メーカー（架空名）。ワークス級

## 規定が生む面白さ

上位パーツを持っていても、クラス規定で装着できない場面をあえて作る。
「持っているのに使えない」制約が、昇格の動機とセッティングの工夫を生む。

## ドライバーライセンス（現実準拠）

- 国内B：18歳以上 + 普通免許
- 国内A：Bの後、講習と試験
- **限定A：満16歳（規定により15歳の年度から）以上18歳未満で、公認カート競技の出場実績がある者**
- 上位カテゴリーは国際B以上

→ ハルカは17歳スタート。幼少期のカート実績で限定Aを取得する。
   18歳でフル、20歳前後で国際 → クラス4〜5への挑戦と重なる。
