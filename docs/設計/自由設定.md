# 自由設定（タイムアタック）設計

置き場：`docs/設計/自由設定.md`
第8場「白紙のページ」の続き。**エンディングを見たあと（`ending.done`）にだけ開く。**

## 入口

```
index.html「白紙のページ」 → 第8場の会話（scenes.json の blank）
  → src/ui/free.html      ← ending.done を確かめるだけ
  → src/ui/setup.html?free=1
```

`free.html` は入口で、画面は持たない。**車の画面は setup.html 1つだけ**にして、
本編と自由設定で同じものを見る（直したら両方に効く）。
`ending.done` は `save.js` の `canFreeSetup()` で見る。入口と画面の両方で確かめるので、
URL を直接叩かれても開かない。

## モードの表

**違いは `setup.html` の `MODE` の表にしかない。** `?free=1` が無いときの挙動は本編そのまま。
新しい違いを足すときは、**表に名前を足してから**その名前を見る側を書く。
テスト S21 が、表に無い名前での分岐と、表の外で `FREE` を直に見ている箇所を落とす。

| 名前 | 本編 | 自由設定 | 意味 |
|---|---|---|---|
| `title` | セッティング | 自由設定 — タイムアタック | 画面の題 |
| `legal` | true | **false** | クラス規定・スポンサー段階を見るか |
| `shop` | true | **false** | 買う・売る・直す・所持金・耐久を出すか |
| `gateCategories` | true | **false** | 区分を解禁段階で隠すか（補強も最初から見える） |
| `fatherNote` | true | **false** | 親父のノートの書き込みを出すか（自由設定は白紙） |
| `harukaNote` | false | **true** | ハルカのノートの欄を出すか |
| `overrides` | false | **true** | 効果値の上書きスライダーを出すか |
| `courses` | class | **all** | 走れるコース（自由設定は5コース全部） |
| `laps` | null | **1 / 3周** | 周回の選択肢（1周＝フライング計測） |
| `persist` | true | **false** | 触った結果を進行に書き戻すか |
| `session` | true | **false** | 予選／決勝のタブを出すか |
| `raceBar` | true | **false** | 下の「ラップ計算／予選へ／決勝開始」を出すか |
| `entryNote` | URL に載せて渡す | **走り方の一言** | コース・周回の行に添える文 |

`persist` が false なのが要点で、**自由設定で何を付けても本編の構成は変わらない**。
進行（`s=`）は読むだけで、書かない。

## 効果値の上書き

装着中の部品の `effects` / `side_effects` の**各数値にスライダーで倍率を掛ける**（±50%）。
元の値を薄い字で並べ、掛けたあとの値と差を見せる。

- 当てるのは `loadoutOf` の1箇所だけ。**`buildPerformance` に渡る前**（`race.js` は触らない）
- 負の値は罰が重くなる向きに伸びる（信頼性 −8 → −12）
- 保存するときは素のままの倍率を捨てる（`packOverrides`）

## 走行

`src/engine/free.js` の `runAttack`。**計算は本編と同じ `simulateRace`**。

- **先頭の1周はアウトラップとして捨てる**＝「1周＝フライング計測」。冷えたタイヤで測らない
- 周回は1周か3周。単独走行なので混雑もグリッドも無い
- 信頼性は効く。負の構成は途中で壊れる（リタイア）
- 結果はセクター別タイムとラップ、この端末のベストとの差

## 記録とノート

タイムとノートは `localStorage` の `haruka.local.v1` の `free` 区画
（`save.js` の `loadLocal` / `saveLocal`、`free.js` の `readFree` / `writeFree`）。
**URL には乗せない**（持ち回る必要が無く、量が読めないもの）。使えない環境では走れるが残らない。
その旨は画面に一行出す。

ベストはコースごと。**速くなったときだけ**差し替え、そのときの構成・上書き値・連続値も一緒に残す。

### 白紙のページ

ベストを更新するたび、**ハルカの字で一行**が自動で増える。

    {コース}　{タイム}　{主な部品を2〜3点}

    ひばり平　1:06.375　ワークス開発エンジン・強化ブロック・オイルクーラー

コースは**短い呼び方**（`courses.json` の `short`）。ハルカも親父も正式名では呼ばない
（「あさひなは前を柔らかく」「みさきは好き。曲がってる」）ので、ノートの字もそちらに揃える。
親父のノートの見出しも同じ。実況・解説は正式名のまま（場内アナウンスなので）。

**ここは数字を出してよい。** ノートに書かれた字であって、口に出す台詞ではない
（ハルカが計器を読まないという禁則は無線にだけかかる。テスト13の対象外）。
主な部品は効きの大きい順。部品が1つも無ければ「素のまま」。

プレイヤーも一行足せる（40字）。ハルカの行の下に、別の字で（明朝／ゴシックと字下げ）。
行は**50行まで**。超えたら古い順に消える。

## 無線

`data/radio.json` の `class5.free_setup`（6本。クラス5台本 第8場から `build-scenes.mjs` が作る）。
どの行を出すかは `free.js` の `freeRadioFor`。既存の症状系（`info`）はこれまでどおり出る。

| 発火 | 条件 | 台詞 |
|---|---|---|
| `fragile_start` | 信頼性が負の構成で走り出す | それ壊れるよ。 |
| `fragile_retire` | その構成でリタイア | 壊れるって言った。→ ……書いとく。「これは壊れる」。 |
| `fast_but_fragile` | 信頼性が負でベスト更新 | 速い。壊れるけど速い。書いとく。 |
| `solid_but_slow` | 信頼性が正で走り切り、届かない | 持つな、これ。つまんないけど持つ。 |
| `best` | 信頼性が正でベスト更新 | （新記録）……書いた。親父、これ知らないやつ。 |

**壊れたときが最優先**（言ったとおりになった、が先）。
信頼性が負で届かなかったときは黙る（毎回言うと「それ壊れるよ」が薄まる）。
走り出す前の一行と走り終えたあとの一行は、**1つの吹き出しに順に並べる**
（走行が一瞬で終わるので、上書きすると先の一行が読めない）。
