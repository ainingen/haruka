# 無線 — ハルカとの交信

## 設計思想

大河の教え：「セッティングは、車の文句に返事をすること」。
車は喋らない。だからハルカが車の代わりに喋る。
プレイヤーはハルカの言葉を聞き、次のセッティングで返事をする。

無線は2種類。**情報系**と**雑談系**。
雑談が混ざっているからこそ、情報系の一言に重みが出る。
全部が重要だと聞き流せなくなる。

### 絶対に守ること

- **答えを言わない。** 「滑る」とは言うが「空気圧を下げろ」とは言わない。判断はプレイヤー
- **レース中はセッティングを変えられない。** 無線は次のセッティングへのヒントであり、その場では何も直せない（大河の教え：始まる前に決めたことで走り切る）
- **ノートを「ハルノート」と呼ばない**（キャラクター.md 呼称ルール）
- 一人称は「ウチ」。主人公は「アンタ」。ごく稀に「おいちゃ……」と言いかけて止まる

## 4つの層

無線は「1周1本」ではない。レース中は実況と無線が主役なので、密度を上げて4層に分ける。

| 層 | 出るタイミング | 中身 | 担当 |
|---|---|---|---|
| **常時** | 走行 9 秒に1本（`RADIO.constant`） | ピット（主人公）の自動コール：前後のギャップ、残り周回、ラップタイム。合間にハルカの状態の一言 | `src/ui/race.html` |
| **反応** | セクター通過ごと、確率 60%（`RADIO.reaction`） | 「よし」「ちっ」「今の見た？」。その車の同じセクターのベストと比べて良し悪しを決める | 判定 `race.js reactionFor`、表示 UI |
| **情報系** | 周の終わりに判定。症状が続く間くり返す | 下表。答えは言わない。悪化すると口調がきつくなる（`harsh`）。ログでは枠を付けて目立たせる | 判定 `race.js radioForLap` |
| **雑談** | 情報系が立たなかった周の隙間 | 進行に関係なし。近くに他車がいればその性格に触れる | UI が台詞を選ぶ |

- **4倍速では常時層と反応を 1/3 に間引く**（`RADIO.constant.thinAtFast`）。スキップ中は情報系と実況だけ残す
- 主人公（ピット）側の台詞は数字を言ってよい（「前まで0.4秒」「あと3周」）。ハルカは言わない

## 情報系（計算結果から自動生成）

race.js の状態を毎周チェックする。優先度が高いものから判定し、1周に最大 `maxInfoPerLap`（2）本。
症状が続いている間は `repeatLaps`（2周）おきにくり返す。悪化したら周を待たずに言い、
以後は `harsh`（悪化版）の台詞になる。同じ症状を `harshAfter`（3）回目からもきつく言う。
出来事（抜いた・抜かれた・好調）は抑制なし。

| 優先 | トリガー | 条件（例） | 台詞（複数からランダム） |
|---|---|---|---|
| 1 | リタイア予兆 | reliability 起因のリタイア確率が閾値超え | 「なんか嫌な音してる」「水温、見えてる？　こっちは見えてない」 |
| 2 | ブレーキフェード | brake_temp が閾値の 90% 超え | 「ブレーキ、奥まで踏んでも止まんなくなってきた」「ペダルが深い。次の周もこれだと怖い」 |
| 3 | タイヤ摩耗 | grip 減衰が 25% 超え | 「後ろが軽い。あと何周？」「もうタイヤ終わりかけ。誰が選んだのこれ」 |
| 4 | アンダー | balance のズレが負方向に 3 以上 | 「前が逃げる。曲がんない」「ハンドル切ってんのに真っ直ぐ行く。おかしくない？」 |
| 5 | オーバー | balance のズレが正方向に 3 以上 | 「後ろ出るんだけど。ウチのせいじゃないよね」「リアが軽すぎ。踊ってる」 |
| 6 | 冷間 | warmup 不足で序盤グリップ低下中 | 「まだ温まってない。3周ちょうだい」「今は無理。タイヤが起きてない」 |
| 7 | 直線で負け | ストレートセクターで後続に詰められた／抜かれた | 「直線で抜かれた。エンジンなに積んでんの」「真っ直ぐで負けるのは悔しい」 |
| 8 | コーナーで負け | コーナーセクターで後続に詰められた | 「コーナーで追いつかれる。足が合ってない」 |
| 9 | 順位変動 | 抜いた／抜かれた | 「抜いた」「……抜かれた」（この2つは短く。感情を乗せない） |
| 10 | 好調 | 全条件クリアで自己ベスト更新 | 「今の周、良かった。車がちゃんと返事してる」 |

### 情報系の書き方

- 症状だけを言う。原因も対策も言わない
- 数字を言わない（「グリップが25%落ちた」ではなく「後ろが軽い」）
- ハルカは車の状態を「感じて」いる。計器を読んでいるのではない
- 同じ症状に通常版4本以上＋悪化版（`harsh`）を用意し、ランダムに出す。1レースで同じ台詞を繰り返さない
- 悪化版は口が悪くなるだけで、やはり答えは言わない（「だから前が逃げるって。何回言えばいい」）

## 反応（セクター通過ごと）

セクターを1つ抜けるたび、高確率で一言。その車の同じセクターのベストに並べば「よし」「今の見た？」、
目に見えて遅ければ「ちっ」「今の失敗」、比べる相手がまだ無ければ「ん」「次」。
セクター種別ごとの一言（「伸びろ」「立ち上がり」）も混ぜる。台詞は `data/radio.json` の `reaction`。

## 常時（ピットからの自動コール）

主人公が読み上げる。数字を言う唯一の話者。テンプレートの `{gap}` `{left}` `{time}` `{car}` `{pos}` を
その場の値で埋める（`data/radio.json` の `constant.player`）。状況が切迫しているものから：
前が近い → 後ろが近い → 残り周回 → 先頭 → ラップタイム → 順位。言うことが無ければハルカの状態の一言。

## 雑談系（進行に関係なし・ランダム）

情報系のトリガーが何も立たなかった周に、確率 35% 程度で1本出す。
1レースで最大6本。雑談の直後の周は出さない。

### コース・状況
- 「ねえ、今日の弁当なに」
- 「隣の青いやつ、さっきから煽ってくる。友達になれそう」
- 「ラジオ入る？　静かすぎて眠い」
- 「今のコーナー、ウチ天才じゃない？」
- 「あ、ヘアピンにネコいた」
- 「観客、何人いる？　……三人？　多いじゃん」
- 「風強くない？　髪がヘルメットの中でぐちゃぐちゃ」
- 「このコース、看板の字が古い。誰も直さないの」
- 「アンタ、ちゃんと見てる？　寝てない？」
- 「おいちゃ……アンタ、聞こえてる？」（稀。1シーズンに1〜2回）
- 「暑い。エアコン付けて」「付いてないよ」「知ってる」
- 「終わったらラーメン。決まり」
- 「あの雲、タイヤの形してる」
- 「無線、ウチの声どう聞こえてる？　変な声してない？」
- 「前の車のテールランプ、片方切れてる。教えてあげたい」

### AI車との絡み（AI車の性格別）
- ストレート型の車に：「あいつ直線だけ速い。コーナーで返す」
- コーナー型の車に：「あいつ曲がるの上手い。真似したい」
- 低速コーナー型に：「あいつ、立ち上がりが変。何かやってる」
- 煽ってくる車に：「後ろ、うるさい。教育していい？」「だめ」「ちぇ」
- 同じ車と何度も競って：「またあいつ。もう顔覚えた」

### コースごとの一言（レース開始直後）
- あさひな：「庭。目つぶっても走れる」
- かざはや：「ここ、ずっと走りたかった」（初走行時のみ）「高いとこから見ると街が小さい」
- ながさわ：「直線ばっかりで退屈。エンジン次第じゃん」
- みさき：「みさきは好き。曲がってる」
- ひばり平：「普通。普通が一番むずかしい」

## プレイヤーの返事

情報系の無線が出たあと、選択肢を3つ出す。
セッティングは変えられない。返事はハルカの調子（consistency）に微小に影響する。

| 返事 | 効果 | ハルカの反応 |
|---|---|---|
| 「わかった、次で直す」 | consistency +小（落ち着く） | 「うん」「頼んだ」 |
| 「我慢して」 | 変化なし | 「……はいはい」「言われなくても」 |
| 「気のせいだろ」 | consistency −小（苛立つ） | 「気のせいで済むならウチ要らないじゃん」「はあ？」 |

雑談系には選択肢を出さない（出すと雑談が「用事」になる）。
ただし「ネコいた」など一部には、一言返せるボタンを1つだけ出す：
- 「集中しろ」→「してるってば」
- 「ネコ？」→「三毛。かわいかった」

## セッティング画面での一言（無線とは別枠）

セッティング画面で、ハルカの好みからズレた設定にしたとき、画面隅に一言出す。
これは無線ではなく、ピットでの会話。

- preferred_balance からアンダー側にズレ：「前、固すぎない？」
- オーバー側にズレ：「後ろ、もうちょい出る方がウチは好き」
- ズレなし：「これ。これが好き」
- 空気圧が高すぎ：「予選用？　決勝もこれで行くの？」
- 前後スタビの片方だけ：「前だけ固めてどうすんの」
- driver_demand が skill を大幅に超えるパーツ：「これ、ウチにはまだ早い気がする」

無視してもいい。無視するとタイムが落ちるのは計算式が既に証明している。

## 実装メモ

- 台詞は data/radio.json に分離。トリガーID → 台詞配列
- 情報系のトリガー判定は race.js の周回状態から行い、UI は結果を受けるだけ
- 表示は順位表の上に吹き出し1つ。前の吹き出しは消す
- ハルカの顔（将来 MJ で用意）を吹き出し横に。表情は「通常 / 不機嫌 / 楽しい / 焦り」の4種で足りる
- 音声は入れない。文字だけ

## 実装（現時点）

| 役割 | 場所 |
|---|---|
| いつ出すかの判定（情報系・雑談） | `src/engine/race.js` の `RADIO` / `radioForLap()` / `radioSymptoms()` |
| 反応の判定 | `src/engine/race.js` の `reactionFor()` |
| 常時層の間隔と内容 | `src/ui/race.html` の `constantTick()`（間隔は `RADIO.constant`） |
| ピットの一言の判定 | `src/engine/race.js` の `pitComment()` |
| 台詞 | `data/radio.json`（判定は持たない。構造は `data/README.md`） |
| レース中の表示 | `src/ui/race.html` — 実況と同じログに流す。情報系は枠付き、返事の3択 |
| セッティング画面 | `src/ui/setup.html` — 画面隅に一言。「ノート通りにする」の直後は「親父ならこうしてた」 |
| 実況 | `docs/設計/実況.md`、`data/commentary.json` |
| テスト | `src/engine/race.test.js` の 10〜16（`npm test`） |

`simulateRace(perf, course, laps, driver, { radio: true })` を渡すと、周ごとの判定結果（配列）が
`result.laps[i].radio` と `result.radio` に入る。無線の乱数は走行の乱数とは別系統なので、
無線を入れてもラップタイムは変わらない。

順位が絡む4つ（`straight_loss` / `corner_loss` / `overtake` / `overtaken`）は engine からは
見えないので、UI が `traffic` として渡す。1台で走らせる `simulateRace` では立たない。

### まだ無いもの

- シーズン末のノート（上記「将来」のまま）
- 音。各台詞に `sound_cue` フィールド（空文字）だけ用意してある
- ハルカの顔。ログでは話者名と文字色で見分けている
