# レース方式

## 表示

- コースはSVGの `<path>` 一本。線で描く。
- 車は点。**自車＝赤、他車＝青**。
- 点の後ろに短い軌跡を残して速度感を出す。
- 順位表を横に常時表示。ラップタイムは周回ごとに更新。
- 倍速ボタン必須（1倍 / 4倍 / スキップ）。

## 走行の計算

物理演算はしない。各車の「進行距離」を毎フレーム加算する方式。

```
座標 = path.getPointAtLength(進行距離)
進行速度 = f(セクター種別, エンジン出力, ダウンフォース, タイヤ状態, ドライバー技量)
```

コースをセクターに分割する。

| セクター種別 | 強く効くパラメータ |
|---|---|
| ストレート | 出力、最高速寄りのギア比、低ドラッグ |
| 高速コーナー | ダウンフォース、剛性 |
| 低速コーナー | 加速寄りのギア比、機械的グリップ、ブレーキ |

セクター構成をコースごとに変えることで、「このコース用のセッティング」が自然に生まれる。

## レース形式

- **スプリント**：20周前後。タイヤ交換なし。一発のセッティング精度で決まる。
- **耐久**：周回多め。タイヤ摩耗と燃料消費が進行し、ピット戦略が加わる。クラス3から解禁。

## 燃料

走る周回数ぶん＋余裕（`WEIGHTS.fuel.margin`）を積んで出走する。**積んだ燃料はそのまま重さになる。**

- 1周で使う量は `fuel_consumption` で増える（`fuelPerLap`）
- 満タンは遅く、減るほど速くなる。20周ぶん積むと序盤は2秒/周ほど重い
- タンクには上限（`tankMax`）がある。それを超える距離は、途中で給油しないと走り切れない
- **給油はピットでのみ**（`refuel`）。ピットストップ自体はまだ実装していないので、いま呼ぶ経路は無い
- **燃料切れはリタイア。** 運ではないので、リタイア判定を切った計算（セッティング画面のラップ計算）でも止まる
- 予選は計測3周ぶんしか積まない。決勝より軽いのはそのため

消費の重いパーツを積むほど、燃料も重くなる。出力の代償が二重にかかる。

## 経済とリスク

- 収入：賞金 + スポンサー料
- 支出：パーツ購入、消耗品、修理
- パーツには耐久値があり、無理なチューンはリタイア率を上げる
- ランニングコストがあることで「勝ち続けないと維持できない」緊張が生まれる

## シーズン

- 1シーズン5〜8戦、ポイントランキング制
- 上位で昇格。降格の有無は未確定（現状は「あり」想定）

## 予選とグリッド

- レースの前に予選セッション（`race.html?session=quali`）。計測3周：アウトラップ → アタック → インラップ。
  アウトとインは `QUALI.outLapFactor` / `inLapFactor` で流す。アタックは決勝と同じ計算（冷間のグリップ低下もそのまま）。
- ベストラップの順がスターティンググリッド。`grid` パラメータ（車 id の並び）で決勝へ渡す。予選を走らなければ `grid=last`（最後尾）。
- 予選と決勝で別のセッティングを持つ（`setup.html` のタブ）。どちらも進行 `state.setup` の中にあり、URL では `s=` 1つで運ぶ（`docs/設計/経済とシーズン.md`）。
- スタート直後の混雑（`START`）：グリッド1列ごとに `slotDelay` 秒遅れて動き出し、最初の `sectors` セクターは
  前車との差が `gapSec` 秒以内だと `gridBlockFactor()` の分だけ遅くなる（差 0 で `maxLoss`）。
  後方スタートは確実にここで払う。予選を走る理由はこれ。
- 出走台数はコース × クラス（`courses.json` の `grid`）。名簿は `data/rivals.json`。
