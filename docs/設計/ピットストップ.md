# ピットストップ・耐久戦 設計 v2

置き場：`docs/設計/ピットストップ.md`
台詞：`data/radio.json` の `pit_stop` 節と `commentary.json`（取り込み済み。追加分のファイルは消した）

実装：`src/engine/race.js` の `ENDURANCE` と `PIT`（**数値はこの2つだけに置く**）、
`src/ui/setup.html`（燃料の3択）、`src/ui/race.html`（合図とボックス）。
テストは S17〜S20（`src/engine/season.test.js`）と 30（`src/engine/race.test.js`）。

## 決めたこと

1. **耐久は6戦のうち1戦だけ。** シーズン第4戦を周回数2倍にする。コースは通常の巡り順のまま
2. **燃料の量はプレイヤーが決める。** 耐久戦のセッティング画面にだけ「燃料」の項目が出る。3択：満タン／必要分＋余裕／ぎりぎり。他の5戦は今までどおり自動
3. **ピットインの合図はプレイヤーが出す。** レース中の無線パネルに「次の周、入れ」を置く。ハルカは抵抗する。押し切らなければ入らない

## 燃料

- 耐久戦は満タンでも走り切れない距離にする（満タン＝全周回の6割）。必ず一度は入る
- 満タン：重い。序盤が遅い。1回のピットで届く
- 必要分＋余裕：中間。1回のピットで届くが、ピットの周を遅らせる余裕は少ない
- ぎりぎり：軽い。速い。ピットを1周でも遅らせると届かない。節約走行と組めば届く
- 燃料の重さは既存の計算（fuel）を使う。ピットで給油する量は「満タンまで」で固定
- 「燃料、節約」の指示：燃費 −10%、周のタイム +0.3%。押している間だけ。ハルカは嫌がる

## ピットイン

- ピット窓：燃料が残り 30% を切った周から開く。開いたらピットが一言（`window_open`）
- プレイヤーが「次の周、入れ」を押す → ハルカが抵抗（`resist`）→ もう一度押す（`insist`）→ 折れる（`comply`）→ 次の周に入る
- 一度押しただけで放置すると入らない。ハルカは走り続ける（`stay_out`）。燃料が尽きれば fuel_out。**これで燃料切れに到達できる**
- 入るときに「給油のみ／給油＋タイヤ交換」を選ぶ。タイヤ交換は摩耗をリセットするが +8秒
- 停止時間：静止 20秒 ＋ 給油（残量に応じて 4〜10秒）＋ タイヤ交換 8秒。ピットロードの通過で別に 15秒
- 停止中は画面に秒数のカウント。ハルカの独り言（`in_box`）が2〜3本流れる
- 出た直後は冷間タイヤ（既存の cold_tire の計算）と満タンの重さ

## AI

- AI も必ず一度入る。入る周は性格で決める：攻め型は遅く（残り 15%）、堅実は早く（残り 35%）、他は 25%。種で ±1周散らす
- AI はタイヤ交換の有無も性格で固定（攻め型＝交換しない、堅実＝交換する）
- AI の停止時間は自車と同じ式

## 画面

- セッティング画面：耐久戦のときだけ「燃料」の行を出す。選ぶとハルカの反応（`fuel_*`）。
  何周ぶん積むことになるかを数字で出す（満タンでも足りないことが読めるように）
- レース画面：無線パネルに「次の周、入れ」「燃料、節約」の2つ。窓が開くまでは押せない（灰色）
- ピット中：順位表はそのまま動く（止まっている間に抜かれるのが見える）
- レース後：ピットで失った秒数と、順位の入れ替わりを結果に一行

## 実況・解説

- 既存の `pit` に追加。新設 `undercut`（ピットが絡んだ順位変動）、`fuel_save`（節約指示を出したとき）、`no_stop_finish`（無給油で走り切った）

## 確定値

**数値はここと `src/engine/race.js` の `ENDURANCE` / `PIT` にしか無い。** 画面には書かない。

### 耐久戦（`ENDURANCE`）

| 名前 | 値 | 意味 |
|---|---|---|
| `round` | 4 | シーズン6戦のうち第4戦が耐久 |
| `lapFactor` | 2 | 周回数は通常の2倍（クラス1なら 8→16、クラス5なら 16→32） |
| `tankShare` | 0.6 | **満タンで走れるのは全周回の6割。** 基準の車（`fuel_consumption` 0）で測る |
| `load.full` | 1.00 | 満タン（＝全周回の60%ぶん） |
| `load.margin` | 0.80 | 必要分＋余裕（48%ぶん） |
| `load.tight` | 0.58 | ぎりぎり（34.8%ぶん） |
| `save.fuel` | 0.90 | 「燃料、節約」で燃費 −10% |
| `save.lap` | 1.003 | 同じく周のタイム +0.3% |

満タンの量は**基準の車で測る**ので、燃費の悪い車はこれより短い距離しか走れない。
`fuel_consumption` がいちばん効くのがこの戦になる。

**3択がなぜ違うものになるか。** 給油は「満タンまで」で固定なので、残して入ったぶんは捨てる。
だから**引っぱるほど総距離が伸びる**。1回のピットで走れる距離は「積んだ量 ＋ 満タン1杯」。

| 方針 | 1回のピットで走れる距離 | 結果 |
|---|---|---|
| 満タン | 0.60 + 0.60 = **1.20** | 余裕。窓が開いてすぐ入っても届く |
| 必要分＋余裕 | 0.48 + 0.60 = **1.08** | 届くが、**入る周はほぼ1周しかない**（早く入ると届かない） |
| ぎりぎり | 0.348 + 0.60 = **0.948** | **届かない。** 節約（×1.111）と組んで 1.053 で届く |

### ピット（`PIT`）

| 名前 | 値 | 意味 |
|---|---|---|
| `window` | 0.30 | 満タンに対する残量がこれを切ったらピット窓が開く |
| `stop.lane` | 15秒 | ピットロードの通過 |
| `stop.still` | 20秒 | 静止しているぶん |
| `stop.fuelMin` / `fuelMax` | 4〜10秒 | 給油。残量が少ないほど長い |
| `stop.tyre` | 8秒 | タイヤ交換を足したときの増分 |
| `ai.attack` / `other` / `steady` | 0.15 / 0.25 / 0.35 | AI が入る残量。攻め型は引っぱり、堅実は早く入る |
| `ai.jitter` | ±1周 | 入る周を種で散らす |
| `aiTyre` | attack のみ false | 攻め型は8秒を惜しんでタイヤを替えない |

停止時間 ＝ `lane + still + (fuelMax − (fuelMax − fuelMin) × 残量割合) + (替えるなら tyre)`。
空に近い状態で給油のみなら **45秒**、タイヤも替えれば **53秒**。

### 早く入った車は二度目を払う

`tankShare` が 0.6 である以上、**残り35%で入る堅実型は一度の給油では届かない**
（0.65 × 0.6 + 0.6 = 0.99 ＜ 1.0）。`other`（25%）も、jitter が悪いほうに出ると届かない。

これを「AI が燃料切れで止まる」ことにはせず、**入らなければ止まるときだけは回数を問わず入る**
ことにした（`aiWantsPit`）。結果として、早く入った AI は二度目のピットを払う。
プレイヤーが「必要分＋余裕」で早入りしたときと同じ理屈なので、罰としても筋が通る。

**ただし数が多い。** クラス3（24周・20台）では 15台中 6〜9台が二度入る。
一度のピットで足りるようにするなら、どちらかを選ぶことになる（どちらもまだ採っていない）。

- AI の割合を下げる：`attack/other/steady` を 0.15 / 0.20 / 0.22 あたりに。性格の差は縮む
- `tankShare` を 0.65 に上げる：設計の 0.15 / 0.25 / 0.35 をそのまま使えるが、「6割」が変わる

### 通しで走らせた結果（自車は純正・パーツなし）

クラス1（みさき・16周・8台）／クラス3（かざはや・24周・20台）、3シード。

| クラス | 満タン | 必要分＋余裕 | ぎりぎり＋節約 |
|---|---|---|---|
| 1 | 6, 7, 6 位（平均 6.3・pit 9周目） | 6, 6, 6 位（平均 6.0・pit 7周目） | 8, 8, 6 位（平均 7.3・pit 6周目） |
| 3 | 12, 13, 15 位（平均 13.3・pit 14周目） | 12, 13, 14 位（平均 13.0・pit 11周目） | 12, 13, 15 位（平均 13.3・pit 9周目） |

どの方針でもリタイアはせず、ピットは1回・45秒（給油のみ）。**差は1着順ぶん**しかない。
節約をレース中ずっと押しっぱなしにした場合の数字なので、ぎりぎりはこれが最悪値になる
（実際には届く見込みが立った時点で切れば、そのぶん速い）。
