# 画面設計 — 紙と画面の二層構造

## 原則

UI は **紙** と **画面** の二層でできている。同じ画面に共存し、紙の上に画面が開く。

| 層 | 何か | 見た目 | 温度 |
|---|---|---|---|
| **紙** | 大河のノート、車両図面、ハルカの一言 | クリーム地、図面の線、手書き風の書き込み | 温かい |
| **画面** | チームの PC。テレメトリ、タイミングモニター、データロガー | 黒地、等幅フォント、緑／白／琥珀の数字、細いグリッド線、状態の点滅 | 冷たい |

「紙のノートを見ながら PC で数字を確認している」現場感を出すのが狙い。
紙は判断の材料（父の言葉、車の形）、画面は事実（数字、順位、温度）。どちらか一方に寄せない。

- **紙の上に画面が開く**（ポップアップ）。逆はない。画面の中に紙が差し込まれるのは、大河の note と無線の吹き出しだけ
- 実写風の車両画像は使わない。紙の層は線画＋製図の作法、画面の層は数字と線だけで「本物っぽさ」を出す
- 画面の層はライト／ダークのテーマに関わらず黒地（PC の画面は自分で光っている）

## 紙の層 — 図面様式

セッティング画面の地は **整備マニュアル / 設計図面の様式**。

### 構成要素

1. **図面枠** — 外枠と内枠の二重線
2. **プロジェクトバー**（左上） — ドライバー名 / クラス
3. **シート番号**（右上）
4. **主ビュー** — 車体側面のシルエット線画
5. **寸法線** — 全長・ホイールベース・車高。両端に矢印、数値は線上に白抜きで乗せる
6. **引き出し線とラベル** — 装着パーツ。図の外側に配置。未装着は「未装着」と表示して枠を残す
7. **DETAIL枠** — ホイール、サスペンションなどの拡大図
8. **部品表** — カテゴリ見出しとスロット行。行をタップすると画面の層（パーツ選択モニター）が開く
9. **親父のノート** — コース × クラスの基準セッティングと書き込み（明朝、手書き風）
10. **ピットでの一言** — ハルカ。紙のまま。無線とは別枠（`docs/設計/無線.md`）

### 動くところ

| 操作 | 画面の変化 |
|---|---|
| 車高を下げる | 寸法値が変わり、シルエットの屋根が実際に下がる |
| パーツ装着 | 引き出しラベルが「未装着」から製品名に変わる |
| ホイール変更 | DETAIL枠のスポーク形状が変わる |
| チューン全般 | 下段の数値が更新される（画面の層。数字が回転して確定する） |

**未装着枠を見せておく**ことが重要。「まだここに何か付く」が成長の予告になる。

### 車体シルエット

- クラス別に4種：ハッチバック / セダン / GT / フォーミュラ
- **すべてノーズが左、リアウイングが右**で統一
- 同一縮尺。クラスが上がるほど車高が下がりホイールベースが伸びる
- 線の太さ1.2px、ホイールは二重円 + ハブ
- 自車は赤、AI車は青で色分け可能な構造にしておく

## 画面の層 — モニター様式

チームの PC。テレメトリとタイミングモニター。

### 見た目の決まり

- **地は黒**（`--mon-bg`）。枠線は細く暗いグレー。グリッド線は 1px の破線か極細の実線
- **フォントは等幅**（システムの monospace。Web フォントは読み込まない）。数字は `tabular-nums`
- **色は4つだけ**：白（通常の値）、緑（良い・自己ベスト更新・効果）、琥珀（注意・閾値に近い・副作用）、赤（危険・閾値超え）。
  順位表の全体ベストだけ紫を使う（タイミングモニターの慣習）
- **見出しは小さい大文字の英字＋字間**（`TIRE WEAR`、`SECTOR 3`）。本文の日本語はそのまま
- **状態は点滅で示す**。赤は点滅、琥珀は点灯。緑は点灯して消える
- **数字は回転して確定する**。装着で変わる値、周回ごとのラップタイムは、旧値から新値へカウントアップ／ダウンして止まる
- 影・グラデーション・角丸を使わない。平面で構成する

### 紙が差し込まれる場所

画面の層の中で、紙の色になるのは次の2箇所だけ。数字の中に人の言葉があることを見せるため。

- パーツ選択モニターの下段：**大河の note**
- レース画面の無線ログ：**ハルカと主人公の吹き出し**（実況・解説はモニターの文字のまま）

## setup.html — セッティング

基本は紙の図面。部品表のスロットをタップすると、図面の上に黒いモニターが開く。

### パーツ選択モニター（モーダル）

```
┌──────────────────────────────────────────────┐
│ PART SELECT  エンジン / 吸気              [✕] │  ← 見出しバー
├──────────────────┬───────────────────────────┤
│ 候補リスト        │ 比較：現在 → 装着後         │
│  ▸ 純正流用       │   レーダーチャート（6軸）     │
│    社外           │   出力 ／ グリップ ／ ブレーキ │
│    ワンオフ 🔒    │   安定 ／ 軽さ ／ 耐久        │
│  装着可否・価格   │   効果（緑）／ 副作用（琥珀）   │
├──────────────────┴───────────────────────────┤
│ ▌大河の note（ここだけ紙の色）                  │
├──────────────────────────────────────────────┤
│ 装着すると ○○ が外れる        [外す] [装着する] │  ← フッター
└──────────────────────────────────────────────┘
```

- **左：候補リスト**。そのスロットを占有しうる全パーツ（ユニット部品は占有する全スロットに出る）。
  クラス順 → 価格順。装着中は先頭に印、規定外・スポンサー段階不足は錠前と理由を出し、選べるが装着はできない
- **右：比較**。選択中の候補を装着したときの車と、いまの車を並べる。
  レーダーチャートは6軸（出力／グリップ／ブレーキ／安定／軽さ／耐久）。**現在＝白の細線、装着後＝緑の面**。
  その下に6軸の数値（現在 → 装着後、差分）と、パーツの効果（緑）・副作用（琥珀）の生の値
- **下：大河の note**。紙の色で差し込む。明朝、罫線
- **フッター**：装着で外れるパーツの警告、「外す」（そのスロットに何か付いているとき）、「装着する」
- **装着すると、比較の「現在」と下段ステータスの数字が回転して新しい値になる**。モニターは開いたまま。
  同じスロットの別の候補をそのまま試せる。閉じるのは ✕ か背景タップ
- 幅 560px 未満では上下に積む（リスト → 比較 → note → フッター）。リストは高さを制限してスクロール

### レーダーチャートの6軸（表示専用）

26 の性能キー（`data/README.md`）を6軸に畳む。**計算には使わない。** 表示側の集計で、重みは `src/ui/setup.html` の `RADAR_AXES` にある。

| 軸 | 畳み込むキー |
|---|---|
| 出力 | `power` `top_end_power` `low_end_torque` `throttle_response` `acceleration` `top_speed` |
| グリップ | `cornering_grip` `downforce` `traction` `road_compliance` `turn_in` |
| ブレーキ | `braking` `fade_resistance` |
| 安定 | `stability` `rigidity` − |`balance` − `preferred_balance`| |
| 軽さ | −`weight` −`unsprung_weight`×2 −`drag` |
| 耐久 | `reliability` −`heat` −`tire_wear` −`driver_demand` |

値は車体基準からの差分なので負にもなる。チャートの半径は「0 が中心と外周の中間」で、目盛の幅はクラスごとの下限を持ちつつ、
現在値と装着後の値が収まるように広げる。

### 下段ステータス（画面の層）

重量 / 出力 / 前後バランス。等幅、大きな数字。値が変わると一瞬点滅し、数字が回転して確定する。

### ラップ計算（画面の層）

コースごとの10周平均を、セクター別（ストレート / 高速コーナー / 低速コーナー）の所要時間の棒グラフで出す。
棒の色はセクター種別、前回との差は棒の端に緑（縮んだ）／琥珀（伸びた）で書く。

### 紙のまま残すもの

主ビュー、DETAIL枠、スライダー、部品表の行、親父のノート、ハルカの一言、出走設定。

## race.html — レース

ベースを **画面の層** に切り替える。黒地。紙は無線の吹き出しだけ。

### タイミングモニター（順位表）

本物のタイミング画面風。1行＝1台。

| 列 | 内容 | 色 |
|---|---|---|
| POS | 順位 | 白。自車の行は地を一段明るく |
| CAR | ゼッケンと名前 | 白 |
| S1 S2 S3 | 直近のセクタータイム（コースのセクターを3等分に畳む） | 自己ベスト比で **緑（更新）／黄（届かず）**、全体ベストなら **紫** |
| LAST | 直近のラップタイム | 白。確定時に数字が回転する |
| GAP | 先頭との差 | 白。周回遅れは `+1 LAP` |

S1〜S3 は距離で三等分し、各組に最低1セクターを残す（`buildSectorGroups`）。**積むのは計画上の通過時間**なので、
S1＋S2＋S3 は LAST とぴったり一致する。一致しない表は信用されない。

**差（秒）は前の車のペースで割る。** 瞬間速度で割ると、その車がストレートにいるか低速コーナーにいるかで
見積もりが3倍近く跳ね、順位とギャップの並びが食い違う。先頭との差は全車が同じ分母になるので、
順位どおりに並ぶ。意味は「前の車がそこを通ってから何秒たったか」。

- 常時表示は先頭＋自車の前後3台。全車はスクロールする別枠（現状どおり）
- リタイアは行を暗くして `OUT`

### 車両情報パネル（テレメトリ）

タイヤ・ブレーキ・燃料をゲージで。

- **ゲージは横棒**。目盛線を細く入れる。閾値の位置に縦線
- 閾値の 90% で **琥珀**（点灯）、超えたら **赤の点滅**。タイヤ摩耗は 60% で琥珀、80% で赤。燃料は 15% で赤
- ブレーキ温度は数字も出す（`128 / 150`）。フェード中は減衰量も
- ラップタイム、ベスト、前後のギャップ、いまのセクターは数字のみ。ギャップは縮むと緑、開くと琥珀に一瞬光る

### コース図

黒地に細い線。セクター種別で色を変えるのは現状どおりだが、線は暗く（`stroke-opacity` 低め）、
自車がいるセクターだけ明るく。**点は発光風**（同色の薄い大きな円を下に重ねる）。自車＝赤、他車＝青。

### 無線ログ

- **ハルカと主人公の吹き出しだけ紙の色**。実況・解説はモニターの文字（白、グレー）
- 情報系（症状）の吹き出しは枠を付けて目立たせる（現状どおり）
- 返事の3択は吹き出しの中に。ボタンも紙の色

### 演出

- **ラップ更新時、ラップタイムが数字回転で確定する**（LAST の列と車両情報パネルのラップタイム）
- セクター通過で S1〜S3 の色が付く
- チェッカーで順位表の自車の行が緑に光る（勝てば数秒、負けても1回）

## 共通 — テーマ変数

変数は **`src/ui/theme.css`** に1箇所で持ち、両画面がそこを読む。CSS 変数を2セット持つ。
**色は変数でしか書かない。** 直書きの色は禁止。

| セット | 接頭辞 | 用途 |
|---|---|---|
| paper | `--paper-*` `--ink-*` `--rule` `--dim` `--accent` `--good` `--bad` | 紙の層。現状の変数名をそのまま使う |
| monitor | `--mon-*` | 画面の層 |

monitor セットの変数。

| 変数 | 意味 |
|---|---|
| `--mon-bg` | 地（黒） |
| `--mon-bg-2` | 一段明るい地（自車の行、選択中の行） |
| `--mon-line` | 枠線・グリッド線 |
| `--mon-text` | 通常の文字（白） |
| `--mon-dim` | 補助の文字（グレー） |
| `--mon-green` | 良い・効果・自己ベスト |
| `--mon-amber` | 注意・副作用・閾値に近い |
| `--mon-red` | 危険・閾値超え |
| `--mon-purple` | 全体ベスト |
| `--mon-car` `--mon-ai` | 自車（赤）・他車（青）。発光風の色 |
| `--mon-font` | 等幅フォントのスタック |

paper セットは `prefers-color-scheme: dark` で青焼き風に変わる。monitor セットは変えない。

切り替わるのは `<html class="paper-ground">` が付いたページだけ。**地が画面の層のページ（`race.html`）では
紙も切り替えない**（クラスを付けない）。そこでの紙は「黒い画面に貼られた紙」という物であって、
ページの地ではないから。古くなった吹き出しは `opacity` で薄めず、`--paper-dim` と `--ink-2` に落として退かせる
（黒地の上で紙を半透明にすると、ただの灰色の箱になって読めなくなる）。

`--car` / `--ai` は紙の赤・青が既定。地が画面の層のページは、自分の `<style>` で
`--car: var(--mon-car)` と指し替える（点は発光風の色になる）。

## 共通 — 書体と文字サイズ

**書体は3つだけ。** すべて `theme.css` の変数を通して指す。直に font-family を書かない。

| 変数 | 何に使うか | スタック |
|---|---|---|
| `--jp-font` | 日本語本文 | `system-ui, "Yu Gothic UI", "Hiragino Sans", "Noto Sans JP", sans-serif` |
| `--hand-font` | 紙の見出し・親父のノート | `"Yu Mincho", "Hiragino Mincho ProN", "Noto Serif JP", serif` |
| `--mon-font` | 数字・ラテン・ラベル | `"JetBrains Mono"` ＋ 等幅フォールバック ＋ 上のゴシック |

**JetBrains Mono は `assets/fonts/` に woff2 で同梱する**（OFL。ライセンスファイルも一緒に置く）。
**CDN からは読み込まない。** `@font-face` の `unicode-range` をラテンに限ってあるので、
同じ要素に日本語が混ざっても、かなと漢字はゴシックへ落ちる。だから「数字だけ等幅で揃える」ことができる。

**文字サイズも変数だけを使う。** px を直に書かない。

| 変数 | px | 何に使うか |
|---|---|---|
| `--fs-micro` | 11 | 図の中の注記。これ以上小さくしない下限 |
| `--fs-label` | 12 | AXIS / SLOT などの小見出し。字間を `--ls-label`（.18em）まで広げる |
| `--fs-sub` | 13 | 補助・注記・無線の話者名 |
| `--fs-small` | 14 | 一段小さい本文 |
| `--fs-body` | 16 | **日本語本文の基準。** 無線の吹き出しもここ |
| `--fs-num` | 18 | モニターの数値 |
| `--fs-last` | 20 | タイミングモニターの LAST |
| `--fs-title` | 22 | 画面名・周回数 |
| `--fs-num-lg` | 28 | ラップタイムの大表示 |

小見出しは**字を大きくするのではなく字間で読ませる**。12px のまま `--ls-label` で開く。

### 幅が足りないときに削る順

タイミングモニターは7列あり、狭い画面では入り切らない。**LAST はこの画面の主役なので最後まで大きさを保つ。**
削るのは「無くても読める桁」から。

1. 420px 以下：セクタータイムの 1/100 秒とギャップの単位を落とし（`.opt` を隠す）、車名をゼッケンだけにする
2. 340px 以下：セクターの列ごと畳む。順位・タイム・ギャップは残す

800px 以上の2カラムでは、右カラム（コース図とタイミングモニター）に列の最低幅が要るので、
左より広くとる（`1fr` : `1.2fr`）。

## 共通 — 演出のイベント名

音は入れない。ただし点滅や数字回転のタイミングを後で音に同期できるように、
**演出はすべて1つの関数 `cue(name, detail)` を通し**、`document` に `CustomEvent('cue')` を流す。
`detail.name` が種類。名前は「対象.出来事」の2語で、両画面で共通。

| name | いつ | 演出 |
|---|---|---|
| `modal.open` / `modal.close` | パーツ選択モニターの開閉 | — |
| `part.select` | 候補を選んだ | 比較パネルの更新 |
| `part.equip` / `part.remove` | 装着 / 取り外し | 数字回転の起点 |
| `number.roll` / `number.settle` | 数字が回り始めた / 止まった | カウントアップ |
| `status.blink` | 下段ステータスの値が変わった | 一瞬の点滅 |
| `lap.set` | ラップタイムが確定した | LAST の数字回転 |
| `sector.green` / `sector.yellow` / `sector.purple` | セクター通過（自己ベスト更新 / 届かず / 全体ベスト） | 列の色 |
| `gauge.warn` / `gauge.alarm` / `gauge.clear` | ゲージが琥珀 / 赤点滅 / 戻った | 点灯・点滅 |
| `gap.shrink` / `gap.grow` | 前との差が縮んだ / 開いた | 緑 / 琥珀に一瞬 |
| `race.checkered` | チェッカー | 自車の行が光る |

無線の台詞は `data/radio.json` の各行に `sound_cue`（現状は空文字）を持つ。
将来これを埋めるときも、鳴らす側は同じ `cue` イベントを聞く。

## 内製と外注の分担

| 内製（SVG / CSS） | 外注（イラスト） |
|---|---|
| 車体シルエット | ハルカの立ち絵・表情差分 |
| パーツ図・分解図 | タイトルのキービジュアル |
| セッティング画面全体 | 父のノートの手書き風ページ |
| コース図・点走行 | |
| モニター様式（レーダー、ゲージ、順位表） | |

図面調のメカと手描きの人物が同居しても、整備ゲームなら違和感にならない。
むしろ「図面の中に生身の人間がいる」対比になる。画面の層が加わると、対比は三つ巴になる：
**図面（父の時代）／ PC（いまのチーム）／ 生身の人間（ハルカ）**。

## 実装の段階

1. `setup.html` のパーツ選択モニター（モーダル）。方向確認のためここで一度止まる
2. `race.html` のタイミングモニターと車両情報ゲージ
3. 残り：下段ステータスの数字回転と点滅、ラップ計算の棒グラフ、テーマ変数の整理（`src/ui/theme.css` に共通化）
