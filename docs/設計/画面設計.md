# 画面設計 — 図面様式

## 原則

セッティング画面は**整備マニュアル / 設計図面の様式**で構成する。
実写風の車両画像は使わない。線画 + 製図の作法で「本物っぽさ」を出す。

## 構成要素

1. **図面枠** — 外枠と内枠の二重線
2. **プロジェクトバー**（左上） — ドライバー名 / クラス
3. **シート番号**（右上）
4. **主ビュー** — 車体側面のシルエット線画
5. **寸法線** — 全長・ホイールベース・車高。両端に矢印、数値は線上に白抜きで乗せる
6. **引き出し線とラベル** — 装着パーツ。図の外側に配置。未装着は「未装着」と表示して枠を残す
7. **DETAIL枠** — ホイール、サスペンションなどの拡大図
8. **下段ステータス** — 重量 / 出力 / 前後バランス

## 動くところ

| 操作 | 画面の変化 |
|---|---|
| 車高を下げる | 寸法値が変わり、シルエットの屋根が実際に下がる |
| パーツ装着 | 引き出しラベルが「未装着」から製品名に変わる |
| ホイール変更 | DETAIL枠のスポーク形状が変わる |
| チューン全般 | 下段の数値が更新される |

**未装着枠を見せておく**ことが重要。「まだここに何か付く」が成長の予告になる。

## 車体シルエット

- クラス別に4種：ハッチバック / セダン / GT / フォーミュラ
- **すべてノーズが左、リアウイングが右**で統一
- 同一縮尺。クラスが上がるほど車高が下がりホイールベースが伸びる
- 線の太さ1.2px、ホイールは二重円 + ハブ
- 自車は赤、AI車は青で色分け可能な構造にしておく

## 内製と外注の分担

| 内製（SVG） | 外注（イラスト） |
|---|---|
| 車体シルエット | ハルカの立ち絵・表情差分 |
| パーツ図・分解図 | タイトルのキービジュアル |
| セッティング画面全体 | 父のノートの手書き風ページ |
| コース図・点走行 | |

図面調のメカと手描きの人物が同居しても、整備ゲームなら違和感にならない。
むしろ「図面の中に生身の人間がいる」対比になる。
