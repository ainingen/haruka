## 書き出し

- 長辺 1280px。**JPEG 85%**（PNG だと1枚 1.4MB で、4枚で配布 ZIP が5MB を超える）
- タイトルだけは長辺 1600px にしたいが、**いまの元画像が 928×1232 しかない**ので
  そのまま（JPEG 86%、171KB）。1600px が要るなら元画像を作り直すところから
- 背景は抜かない。写真のまま置く（部品の線画とは別の層）

いまの書き出し：

| ファイル | 大きさ | 容量 |
|---|---|---|
| `haruka_arcade.jpg` | 1280×853 | 154 KB |
| `haruka_note.jpg` | 1280×853 | 126 KB |
| `haruka_walk.jpg` | 853×1280 | 144 KB |
| `haruka.jpg`（タイトル） | 928×1232 | 171 KB |

## 場面での出し方

場面エンジン（`src/ui/scene.js`）の手：

```js
{ stage: '立ち絵：scene/haruka_note.jpg', do: 'image', src: 'scene/haruka_note.jpg' }
```

- 画像は場面の背景として全面に敷き、**下から暗くして台詞を読ませる**（`.scene-photo`）
- 敷いている間は台詞の枠を下に寄せ、地を透かして白い字に切り替える（`.has-photo`）
- 次に `image` が来るまで同じ絵のまま。**`fade` で消える**。場面が終わっても消える
- **画像が無ければ何も敷かない**（`img.decode()` に失敗したら黙って台詞だけで進む）
- `src` は assets からの相対。ページごとの入口は `playScene` の `imageBase`
  （`index.html` は `assets/`、`src/ui/*.html` は `../../assets/`）

### どこに入れるか

差し込みは**台本には書かない**。`tools/build-scenes.mjs` の `IMAGES` が、
指定した【 】の直後に手を足す（当たらなければビルドが落ちる）。

| 場面 | 画像 | 入れる位置 |
|---|---|---|
| 第4場 ゲームセンター | `haruka_arcade.jpg` | 【暗転からカット。派手な筐体の光…】の直後 |
| 第5場 クラス5昇格 | `haruka_note.jpg` | 【season.html。昇格判定のあと…】の直後 |
| 第6場 優勝 ピットレーン | なし | — |
| 第6場 最後 | `haruka_walk.jpg` | 【ハルカ、それ以上は何も言わず…ガレージへ歩いていく】の直後 |
| 第7場 エンディング | `haruka_note.jpg` | 【作業灯だけ。トロフィーは作業台の端に…】の直後 |
| 第8場 白紙のページ | `haruka_note.jpg` | 場面の頭（冒頭の暗転の直後） |

第6場のピットレーンには絵が無い。ここは台詞だけで進め、最後に歩き去る絵で閉じる。
テスト S15 が、この置き場所と絵の実在・容量を見張る。

## タイトル画面

`index.html` と `src/ui/title.js`。詳しくは `docs/設計/画面設計.md`。

- **body の最初の要素が canvas**（PLiCy はそこからサムネイルを撮る）
- canvas に `haruka.jpg` を敷き、下三分の一に横組み二段
  上段（小）「ハルカの」／下段（大）「セッティングノート」、左右中央揃え
- 下側だけ暗くする縦グラデーションを敷いて白文字を読ませる
- 論理サイズ固定（1200×1500）、`devicePixelRatio` を見て描画解像度を上げる
- **画像の読み込み前でも canvas は存在させ、地色と文字だけ先に描く**
- ボタン（はじめから／つづきから／白紙のページ）は canvas の外に HTML で
- **画像が無くても壊れない**（地色＋文字だけで成立）

題字は2案あり、`TITLE.style` で切り替わる。既定は `'sticker'`（斜体＋多重の縁取り）、
もう一方は `'board'`（電光掲示板＋その下に日本語）。
