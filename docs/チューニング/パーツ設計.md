# チューニング — カテゴリとパーツ設計

## 原則

**すべてのパーツにトレードオフを持たせる。** 上位パーツ＝単純上位、にしない。
コースとレース形式によって最適解が変わることで、プレイヤーは攻略ではなく理解に向かう。

各パーツは以下の4点を持つ。

- **説明** — 何をする部品か（教材としての役割）
- **効果** — どのパラメータが上がるか
- **副作用** — 何を失うか
- **解禁段階** — どのクラス / スポンサー段階で入手可能か

説明文は本編では「父・大河のセッティングノートの書き込み」として提示される。
クラス5帯ではノートに記載がない領域に入り、「ここからは自分で書く」に切り替わる。

## 6カテゴリ

### 1. エンジン
| 項目 | 効果 | 副作用 |
|---|---|---|
| 吸気（エアクリ、インマニ） | 出力小増 | 吸気音、低速トルク微減 |
| 排気（マフラー、エキマニ） | 出力中増 | 重量変化、音量規定 |
| 燃調（ECU） | 出力増、レスポンス | 燃費悪化 |
| 過給（タービン、ブースト圧） | 出力大増 | 発熱、耐久低下、ラグ |
| カム | 高回転域が伸びる | 低速トルクが死ぬ |

軸となる理屈：**出力を上げるほど、熱と耐久が犠牲になる。**

### 2. 駆動系
| 項目 | 効果 | 副作用 |
|---|---|---|
| ファイナルギア比 | 加速 or 最高速 | 一方を取れば一方を失う |
| LSD | コーナー脱出のトラクション | タイヤ摩耗増、直進時の癖 |
| クラッチ | 伝達効率、変速速度 | 操作の繊細さ（技量依存） |

軸となる理屈：**加速と最高速はトレードオフ。コースのストレート比率で決まる。**

### 3. 足回り
| 項目 | 効果 | 副作用 |
|---|---|---|
| バネレート | 過渡の安定、応答 | 硬すぎると路面追従が落ちる |
| 減衰力 | 挙動の収まり | 合わないと跳ねる／沈む |
| 車高 | 重心低下、空力効率 | 下げすぎるとストローク不足 |
| キャンバー | コーナリンググリップ | 直進時の接地面減、偏摩耗 |
| トー | 直進安定 or 回頭性 | 抵抗増、摩耗 |
| スタビライザー | ロール抑制 | 前後バランスが崩れる |

軸となる理屈：**前後のバランスでアンダー／オーバーが決まる。**
単体の良し悪しではなく、前後の相対関係が挙動を作る。

### 4. タイヤ
| 項目 | 効果 | 副作用 |
|---|---|---|
| コンパウンド（ソフト〜ハード） | グリップ | 柔らかいほど摩耗が早い |
| 空気圧 | 温まりの早さ、接地形状 | 高いと早くタレる、低いと温まらない |

軸となる理屈：**予選は短い、決勝は長い。** プロローグで父が教える内容そのもの。

### 5. ブレーキ
| 項目 | 効果 | 副作用 |
|---|---|---|
| パッド | 制動力、耐フェード | 対ローター攻撃性、冷間時の効き |
| ローター径 | 制動力、放熱 | ばね下重量増 |
| 前後配分 | 進入姿勢の作り方 | 偏るとロック |

### 6. 軽量化・空力
| 項目 | 効果 | 副作用 |
|---|---|---|
| 軽量化 | 全域で有利 | 剛性・耐久低下、リタイア率上昇 |
| ダウンフォース（ウイング、スプリッター） | コーナー速度 | ドラッグ増、ストレート速度低下 |

軸となる理屈：**空力は「コーナーで得た分をストレートで払う」。**

## 解禁とスポンサー

| 段階 | 状態 | 入手できるもの |
|---|---|---|
| 0 | 無名 | 中古パーツ、純正流用のみ |
| 1 | 地元スポンサー（整備工場、飲食店） | 社外パーツ解禁 |
| 2 | 地方チェーン | ワンオフ、セミワークス級 |
| 3 | 全国企業（架空名） | 開発パーツ |
| 4 | 大手メーカー（架空名） | ワークス級、専用設計 |

資金とパーツ解禁の両方が段階化される。
